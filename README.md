This project demonstrates the basic movement and AI-based navigation capabilities of the JetBot robot using Python programming and deep learning. It includes three main stages: basic motion control, model training, and real-time demonstration.

In the first stage, the basic motion control program is used to move the JetBot forward, backward, left, and right. In the second stage, a machine learning model is trained using collected images to recognize the environment and identify clear or blocked paths. In the final stage, the trained model is integrated with the JetBot camera and motor control system to perform real-time predictions and guide the robot's movement.

This project provides a practical understanding of robotics, computer vision, and artificial intelligence by combining motor control, model training, and live testing into a single workflow.

## Main Modules

**1. Basic Motion:** Controls the JetBot's movement in different directions using Python and motor commands.

**2. Model Training:** Trains a deep learning model using labeled images to identify the required environment conditions.

**3. Live Demo:** Uses the trained model and live camera input to make predictions and control the JetBot during real-time operation.

## Technologies Used
- NVIDIA Jetson Nano
- JetBot Robotics Platform
- Python Programming
- PyTorch
- Computer Vision
- Deep Learning

## Expected Outcome

The project demonstrates how basic robot movement, machine learning, and real-time camera processing can work together to develop an AI-enabled mobile robot. It also provides a foundation for learning autonomous navigation and obstacle avoidance.
